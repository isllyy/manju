# Quality Gates

## 一级：身份一致性（不通过就返工）

- [ ] Hero、三视图、动作、表情是否明确是同一个人？
- [ ] 脸型、眼型、鼻型、嘴型、下颌线是否稳定？
- [ ] 年龄感是否稳定？
- [ ] 发际线和发型结构是否连续？
- [ ] 是否出现“更漂亮但不是本人”的 AI 网红脸？

## 二级：结构一致性

- [ ] 正侧背服装结构能否物理连续？
- [ ] 标志性配饰是否没有随机消失或新增？
- [ ] 身高、肩宽、腿长等比例是否稳定？
- [ ] 左右手配饰是否乱换？

## 三级：资产价值

- [ ] 是否包含后续生产真正需要的视角？
- [ ] 动作是否覆盖角色常用场景？
- [ ] 表情是否有明显差异但身份不漂？
- [ ] 细节特写是否能帮助后续锁定服装/发型/道具？

## 四级：版式质量

- [ ] 是专业角色资产板，不是廉价拼贴？
- [ ] Hero 有明确视觉主次？
- [ ] 留白与网格是否稳定？
- [ ] 标签是否简洁、可读？
- [ ] 中文文字错误是否可接受？若文字不稳，应减少图内文字并后期排版。

## 返修优先级

1. 身份漂移
2. 发型 / 服装锚点漂移
3. 身体比例
4. 手部与道具
5. 版式
6. 文字
