# 示例：通信伊姐 IP 角色资产

> 这是 `yishui-juesezichan` 的公开示例。它演示如何把一个已经建立的 Q 版 IP 形象沉淀成可连续调用的 Character Bible，而不是每次重新生成一个“差不多”的角色。

## 输入

用户提供一张“通信伊姐”IP 母图，并提出：

> 以这个 IP 为身份母版，建立完整角色资产。后续工作形象、生活形象、海报、故事板都必须保持是同一个“通信伊姐”。

## Character DNA

### Identity

- 名称：通信伊姐
- 定位：通信 × AI 科普与应用型 IP
- 角色气质：专业、亲和、活力、愿意分享
- 视觉语言：明亮通信蓝 + 暖白 + 少量米杏色
- 风格：高品质 3D Q 版 / 潮玩角色渲染，干净、可爱但不幼稚

### Immutable Visual Anchors

1. 大头小身的 Q 版比例与圆润面部轮廓
2. 黑色长直发与整齐刘海
3. 大型棕色明亮眼睛与自然微笑
4. 蓝色棒球帽，帽前白底黑色 `AI` 标识
5. 白蓝拼色通信工作 Polo 上衣
6. 米杏色高腰短裤与腰带
7. 米杏色斜挎包
8. 蓝白通信科技主色与亲和专业气质

These visual anchors are immutable. Do not redesign, simplify, replace, remove, or reinterpret them across views, poses, expressions, or scenes.

## 资产板规划

### Hero

保留母图最有识别度的扶帽动作，作为角色 Hero Pose。

### 三视图

- 正面：自然站立，完整展示帽子、Polo、短裤、斜挎包与鞋履
- 侧面：严格保持发长、帽檐、包带与身体比例
- 背面：重点固定长发轮廓、帽后结构、上衣拼色与包带走向

### 工作形象

- 会议汇报：手持平板，专业表达
- 方案研讨：使用笔记本电脑讨论 AI 应用
- 项目推进：手持项目板或任务清单
- 直播分享：面对镜头讲解通信与 AI
- 培训赋能：面向学员教学与互动
- 一线调研：进入营业厅、社区或通信现场

### 生活形象

- 城市打卡 / 旅行摄影
- 阅读与学习
- 跑步 / 健身
- 旅行探索
- 居家休闲
- 兴趣与社交

### 表情库

自然微笑、俏皮眨眼、开心喜悦、思考沉思、惊喜可爱、比心感谢。

### 细节资产

AI 帽标、通信工牌、Polo 拼色结构、斜挎包、鞋履、手表/腕部配饰。

## Before → After

**Before：** 一张单独 IP 图。能看出角色是谁，但没有三视图、表情、动作、服装规则，也没有后续连续生成约束。

**After：** 一套可复用角色资产系统。后续可以直接调用“通信伊姐”去演会议、直播、培训、旅行、短剧和故事板，而不是重新设计人物。

## 关键结论

角色资产的价值不是“一张图更漂亮”，而是把一个视觉形象升级成 **可持续调用的数字演员**。
